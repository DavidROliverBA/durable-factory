How the Durable Factory works

You describe a change. A pipeline of AI agents plans it, builds it, tests it and reviews it in its own git branch, then waits for your approval before shipping. The difference from other agent pipelines is that it's durable: kill the server at any moment (the 💥 button does exactly that) and every run carries on from its last checkpoint. Nothing is lost, and nothing irreversible happens twice.

The pipeline

Intake → Plan → Commit plan → Build → Test ⟲ fix (≤3) → Review ⟲ revise (≤2) → Approve (you) → Ship → Report
          │                     │          │                 │                     │
       planner              builder    the suite         reviewer          approve · decline ·
     (writes plan.md)    (code, not      decides         (read-only)       send back with a note
                           tests)

Rules the code enforces, not the agents

  • Write scope. Before each agent turn the factory snapshots the files. Afterwards, any change outside the role's scope is rolled back and fails the run. The planner may only write plan.md, the reviewer nothing, and the builder never the tests.
  • Claims vs reality. Each agent ends by writing a JSON result. The builder's list of changed files is checked against the real git diff. A mismatch goes back to the same agent to fix, up to 3 turns.
  • Bounded loops. At most 3 test attempts and 2 review revisions. Then it fails closed and leaves the branch for you to inspect.
  • Budget. Model spend is checked before every agent turn.

What durability means here

  • Every phase is a checkpoint, and every agent is its own conversation saved in SQLite.
  • A tool call that was cut off comes back as interrupted. Then the factory's checks decide: if the result file is missing, the agent gets a correction turn.
  • Values that must not be recomputed after a crash are saved once and reused: the "before" file snapshot, test results, commits, the push and the PR.
  • The approval wait is itself durable. Leave it overnight with the server off, and it's still waiting.
